# limit_mistake_finder

Tampermonkey-скрипт **TH Management — Limit Mistake Finder** (`limit-mistake-finder.user.js`).

Проходит **все страницы** текущего фильтра на `paymentsupport` и `ExtendedPaymentRequestList`, берёт тикеты в статусе **Credited (M)** и сравнивает **Amount by receipt** с лимитами их **Subagent** со страницы Confluence «ЛИМИТЫ РУЧНЫЕ». Тикеты ниже или выше лимита показываются списком, и их можно скачать в Excel.

## Установка
1. Tampermonkey → «Создать новый скрипт» → вставить содержимое `limit-mistake-finder.user.js` → сохранить.
2. Залогиниться в Confluence (`doc.office.lan`) в этом же браузере: скрипт загружает страницу лимитов с вашими куками.
3. При первом запросе к `doc.office.lan` Tampermonkey спросит разрешение — нажать «Always allow domain».

## Как пользоваться
1. Открыть List of payment queries (или Extended) и задать фильтр. Чтобы проверка шла быстрее, можно сразу отфильтровать по статусу Credited (M).
2. Нажать **APPLY**: скрипт перехватит запрос списка (в панели появится «✅ Фильтр пойман»).
3. Открыть панель кнопкой **Limits** справа внизу (или Alt+L) → **▶ Проверить все страницы**.
4. Результаты на вкладках:
   - **Ниже лимита** / **Выше лимита** — Ticket ID (клик копирует), Subagent, сумма, Min, Max, отклонение, раздел Confluence;
   - **Не удалось проверить** — субагента нет в Confluence, лимит в Confluence не распознан, найдено несколько строк с разными лимитами или не читается сумма. Причина указана в строке.
5. **⬇ Скачать Excel**: в файле листы «Ниже лимита», «Выше лимита», «Не удалось проверить» и «Сводка» (по субагентам и итоги обхода).

## Первый запуск — «🩺 Диагностика»
Ключи JSON списка и формат таблицы в Confluence скрипт определяет автоматически:
- ключи полей берутся из **таблицы на экране**: значения колонок Amount by receipt / Subagent / External Status сверяются с ответом сервера. Если так не получилось, поля ищутся по названию ключа;
- в Confluence первый столбец — субагент, лимиты берутся из колонок Min/Max (От/До) или из текста вида `100 - 5 000`, `от 100 до 5000`, `min 100 / max 5000`. Зачёркнутые строки используются, только если других нет.

«Диагностика» показывает, какие ключи выбраны (с примерами значений), все ключи первой строки и как разобрались строки Confluence: что распознано, а что нет.

## Настройки (блок `CONFIG` в начале скрипта)
- `statuses` — какие статусы проверять (по умолчанию `['Credited (M)']`).
- `fields` — явно задать ключ JSON, если автоопределение ошиблось, например `amount: 'amountByReceipt'`.
- `limitOverrides` — ручные лимиты, они важнее Confluence: `'Vodafone Cash': { min: 100, max: 30000 }`.
- `limitsPageUrl` — адрес страницы лимитов.
- `pageDelay`, `pageRetries`, `pollInterval`, `pollMax` — темп обхода страниц и повторы при ошибках.
